## Что это

Мини-приложение Telegram: игра целиком локальная, партия лежит на устройстве
и работает без сети. Цикл — это ход: энергия тратится на действия, завершение
цикла приносит доход и поднимает угрозу. Чем шире империя, тем громче её
слышно — иммунная система отвечает рейдами и отбивает окраины.

Партия заканчивается низложением Суверена и осадой: пятнадцать циклов
контрнаступления, которые надо выстоять. После победы открывается New Game+,
где система помнит прошлую империю и давит тем сильнее, чем дольше вы тянете.

**Объём:** 38 секторов в четырёх регионах, 29 событий, 29 модулей, 15
технологий, 15 доктрин в трёх взаимоисключающих путях, 19 противников,
8 мутаций, 8 эпох, 34 достижения, 12 глав летописи. Два языка: русский и
английский.

## Из чего состоит

```
src/engine/          движок: reduce(state, action) → { state, notices }
  content/           весь контент: секторы, события, модули, враги, лор
  systems/           бой, угроза, логистика, летопись
  sim/               боты и харнесс для измерения баланса
  save/              сериализация, миграции, санитайзинг, облако
src/store/           мост движка и React (Zustand + Immer), персистентность
src/ui/              вкладки, оверлеи, хуки
src/i18n/            словарь интерфейса + пакеты перевода контента
src/telegram/        SDK мини-приложения, темы, хаптика, офлайн
public/sw.js         service worker
scripts/             балансные прогоны и бюджет размера сборки
```

Пять вкладок: **Штаб** (действия цикла), **Карта** (секторы и захваты),
**Развитие** (модули, доктрины, технологии), **Хроника** (журнал, летопись,
награды), **Настройки** (язык, тема, хаптика, сохранения, справка).

## Системные детали

**Движок отделён от интерфейса.** Всё, что относится к правилам, живёт в
`src/engine` и проверяется юнит-тестами без браузера. Движок не знает про
React и DOM.

**Случайность детерминирована.** Никакого `Math.random()`: генератор
(mulberry32) ключуется парой `(seed, rngCursor)`, поэтому партия полностью
воспроизводится по зерну. На этом стоит весь харнесс баланса.

**Сейв — недоверенные данные, даже собственный.** Всё, что приходит из
хранилища, проходит `sanitizeState`: неизвестные значения заменяются
умолчаниями, а не роняют игру. Прогресс пишется в `localStorage` отложенно
(и немедленно при уходе страницы), раз в несколько циклов кладётся снимок в
автослот, а через CloudStorage Telegram партия переносится между
устройствами. Есть текстовый код партии — сжатый, если браузер умеет
`CompressionStream`.

**Баланс измеряется, а не оценивается на глаз.** В `src/engine/sim` описаны
20 стилей игры — от взвешенных до крайностей вроде «не лечиться вовсе» или
«не воевать вообще». `npm run balance` прогоняет по 50 партий каждым и
печатает доли побед, гибелей и медианы. Крайности нужны, чтобы видеть, какие
системы действительно держат игру: например, отказ от лечения роняет победы
с 86% до 34%, а отказ от боя — до нуля.

**Офлайн и размер.** Service worker кэширует оболочку при установке, читая
список файлов из самой `index.html`. Первая загрузка — около 124 КБ после
сжатия; за этим следит бюджет размера в CI, который падает при превышении.

**Строгий TypeScript:** `exactOptionalPropertyTypes`,
`noUncheckedIndexedAccess`, `verbatimModuleSyntax`.

## Запуск

```bash
npm install
npm run dev
```

Игра работает только внутри Telegram: обычный браузер видит экран со ссылкой
на бота. Для разработки гейт обходится параметром `?playtest=hem`.

| Команда                     | Что делает                                             |
| --------------------------- | ------------------------------------------------------ |
| `npm run dev`               | Дев-сервер                                             |
| `npm run build`             | Проверка типов и продакшен-сборка                      |
| `npm run verify`            | Полный прогон: типы → линтер → формат → тесты → сборка |
| `npm run test`              | Юнит-тесты движка                                      |
| `npm run e2e`               | E2E-сценарии интерфейса (Playwright)                   |
| `npm run size`              | Бюджет размера по чанкам (нужна сборка)                |
| `npm run balance`           | Балансный прогон: 50 забегов каждым стилем             |
| `npm run balance:mutations` | Замер мутаций по отдельности                           |
| `npm run test:balance`      | Медленные проверки жизнеспособности стилей             |
| `npm run deploy`            | Сборка и публикация на GitHub Pages                    |

Проверять правки нужно целиком и без пайпов, глотающих код возврата:

```bash
set -eo pipefail && npm run verify && npx playwright test
```

### Как подключить своего бота

1. В [@BotFather](https://t.me/BotFather) создайте бота и через
   `/newapp` привяжите Mini App к адресу сборки.
2. Задайте кнопку меню: `/setmenubutton` → URL приложения.
3. Разверните проект (`npm run deploy` или GitHub Actions) и откройте бота.
